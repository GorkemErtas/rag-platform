# Aurora Garden — fictional support runbook

This runbook is fabricated for a public portfolio demo. Names, thresholds and incident details are invented.

For a missing plant icon, refresh the garden once. If it remains missing, record the browser name and puzzle number. Escalate to the fictional support group called Lantern Keepers. Never request passwords or personal data.

In a fictional incident on 8 March 2026, an incorrect asset path caused missing moonflower icons. The team corrected the path and added an asset-reference check. No user records were involved.

The fictional release checklist requires keyboard navigation, English and Spanish text checks, and a compressed asset bundle below 400 kilobytes. An operator reviews the checklist before publishing a release.
